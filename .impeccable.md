# VarsityMart Design Context

## Design Context

### Users
University students in Ghana — both buyers and sellers operating on campus. They're browsing between lectures, ordering food on the go, quickly listing items to earn side income, and chatting with classmates about deals. The context is mobile-first, fast-paced, and social. A secondary audience is campus store and restaurant operators managing their presence on the platform.

**Job to be done**: Find what I need fast, trust the platform with my money, and feel good about the experience while I'm doing it.

### Brand Personality
**Bold · Energetic · Youthful**

VarsityMart is not a corporate tool. It's the campus marketplace — lively, direct, and unapologetically student-owned. The interface should feel like it was designed specifically for Ghanaian campus life, not adapted from a global template.

### Emotional Goals
Students should feel:
- **Confident** — the platform is solid, trustworthy, worth putting their money into
- **Focused** — they can find what they need without friction or noise
- **Delighted** — using it is genuinely pleasant, not just functional

### Aesthetic Direction
**Uniquely Ghanaian campus energy** — not Jumia, not Depop, not a Shopify template. Draw from the warmth and directness of West African design sensibility: bold typography, warm neutrals, orange energy.

**Reference direction**: Clean marketplace confidence meets campus vitality. Think editorial product presentation with youthful warmth. The orange is the accent — used deliberately for action, not decoration.

**Anti-references — explicitly avoid**:
- Dark/techy SaaS aesthetic (glowing accents, dark backgrounds, dashboard vibes)
- Cluttered and noisy (too many competing elements, poor hierarchy)
- Bland and forgettable (generic e-commerce clone, could be any app)

### Color System
```
--ink:          #27272a   /* primary text */
--ink-2:        #52525b   /* secondary text */
--ink-3:        #a1a1aa   /* muted/placeholder */
--ink-4:        #e4e4e7   /* borders, dividers */
--bg:           #f4f4f5   /* page background */
--surface:      #ffffff   /* cards, panels */
--orange:       #f97316   /* primary action */
--orange-dark:  #ea580c   /* pressed/hover */
--orange-dim:   #fff7ed   /* tinted backgrounds */
--orange-border:#fed7aa   /* orange-tinted borders */
```

### Typography
```
--font-heading: 'Plus Jakarta Sans'     — bold, display weight for headings
--font-body:    'Bricolage Grotesque'   — body, UI labels, navigation
--font-mono:    'IBM Plex Mono'         — prices, codes, data
```
Use `Plus Jakarta Sans` at heavy weights for headings to communicate boldness. `Bricolage Grotesque` is expressive but legible for body copy. Prices in `IBM Plex Mono` make numbers feel precise and trustworthy.

### Layout & Density
**Balanced** — standard marketplace grid with comfortable breathing room. Product-first. Not airy editorial, not cramped Jumia-density. Sections are well-separated; cards have room without feeling sparse.

### Design Principles
1. **Campus-native confidence** — solid, trustworthy UI that students feel safe handing money to. Clear states, clear feedback, nothing ambiguous.
2. **Focused clarity** — the fastest path to the thing they want. Hierarchy does the work; decorative noise is cut.
3. **Warm orange energy** — the primary color earns its presence. Used only for primary actions, key highlights, and brand moments — never as decoration.
4. **Balanced density** — enough information to browse efficiently, enough space to breathe. Not a dashboard, not a landing page.
5. **Authentically Ghanaian** — fresh, not derivative. Typography and spacing choices that feel original to this context, not adapted from a global template.

### Radius & Shadow
```
--r:     6px                                              /* consistent border radius */
--sh-sm: 0 1px 3px rgba(0,0,0,0.07), 0 1px 2px rgba(0,0,0,0.05)
--sh-md: 0 4px 16px rgba(0,0,0,0.07), 0 1px 4px rgba(0,0,0,0.04)
--sh-lg: 0 8px 32px rgba(0,0,0,0.10), 0 2px 8px rgba(0,0,0,0.06)
```
Shadows are light and warm — they create depth without heaviness. No thick colored borders as accents.

### Auth Page Direction
Split-screen layout: dark `#27272a` left panel with grid texture, VarsityMart branding, and a campus illustration — white right panel with the form. Hidden left panel on mobile. This communicates confidence and brand identity from first contact.

### Component Conventions
- Cards: `bg-surface border border-ink-4 rounded-[--r] shadow-[--sh-sm]`
- Primary buttons: `bg-orange text-white` — only one primary CTA per view
- Muted text: `color: var(--ink-3)` — never gray on colored backgrounds
- Price display: `font-mono font-bold` — numbers feel precise
- Badges: orange-tinted background (`bg-orange-dim text-orange-dark`) for "hot", "new", etc.
